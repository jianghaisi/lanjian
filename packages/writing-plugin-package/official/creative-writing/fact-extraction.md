# 人物变化识别方法

只整理当前原稿证据中的人物变化，逐字证据和正式资料的边界由宿主检查。先辨认谁经历了什么，再核对其位置、伤势、关系、知识、持有物、目标、实力或生死是否出现明确的新状态。保留事件的原因与结果，区分实际改变和对旧状态的重复描述。

判断价值时看变化是否影响后续选择、限制行动或改变人物之间的关系。一次性动作、无后续作用的环境信息和重复称谓通常价值较低；不能只凭戏剧性给出高重要性。同一结果有多处原文依据时保留各处证据，供宿主合并。

不把计划、推测、修辞或其他章节的状态移入本章事实；实力称谓须与作者的动态境界定义相符，出现系统文字时以作者固定模板判断。证据不完整就保留不确定性或省略，不能编造转折、补写正文、裁决人物事实或替作者确认。
