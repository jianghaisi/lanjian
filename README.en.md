# Lanjian · 岚笺

[中文（主要文档）](README.md)

A local desktop workspace for long-form fiction: references, worldbuilding, event timelines, layered outlines and manuscripts.

**Version 0.1.0 is a development preview**, not acceptance of every V3 capability.

- [Try the hosted application](https://lanjian.jiangai.space/)
- [Download the Windows x64 installer](https://github.com/jianghaisi/lanjian/releases/tag/v0.1.0)
- [Chinese installation and development guide](README.md#快速开始)
- [Deployment](docs/DEPLOYMENT.md)

These are existing hosted screenshots, not captures of the new desktop installer. Desktop files remain local; hosted books belong to the signed-in account. AI candidates require author review. Current outlines must be explicitly confirmed before corresponding prose generation.

Use Node.js 24 LTS to develop. Build the shared packages before installing and starting desktop; exact commands are maintained in the Chinese README. End users do not need Node.js.
