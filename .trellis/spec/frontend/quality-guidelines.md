# Renderer quality gates

- 非写作页面的状态栏行高必须随真实内容预算，不能外框预留 1.5rem、内层又设置更大的 min-height。人物档案原生验收检查 html/body/app-frame 与档案根的实际纵向溢出，并检查详情/筛选在窗口内，避免 4px 底栏溢出被外层隐藏掩盖。
- Windows Electron 原生 select 驱动采用可验证的方向键（当前 `keyCode: 'Down'` 对应 DOM `ArrowDown`），先验证真实键盘/输入/change 和实际 value。字符串 `ArrowDown` 在当前发送接口中不能证明收到方向键；不得绕过验证改写 DOM value。

- 2026-09-08 参考图回归必须分别检查 html/body、作品库根和内容区的纵向溢出，不能只检查 scrollWidth。主标题、继续创作、最近作品和右插画均应在视口内；长目录只允许列表内部滚动。两套加载主题的 boot/work 根与内部滚动区都须检查，关闭按钮需真实命中。
- 稿纸行线单一绘制层为 `.cm-content`，`background-position-x:50%`、有限背景宽度及对称滚动条 gutter 共同保证左右留白；只比较 background-position 不能证明外部滚动条占位对称。
- 宠物回归需真实拖动、方向键移动、形态持久化、隐藏/恢复及实际 transform 变化；在 125% 缩放下再次验证新建章节与发送按钮命中。减少动画必须验证位移停止，不只检查设置勾选。

- 加载中的正文节点可以已挂载但仍处于 `.app-frame[inert]`。编辑烟测必须等待真实作品载入结束、解除 inert，再验证鼠标命中和编辑器焦点后发送原生选择快捷键；禁止仅等待 `manuscript-input` 存在就操作，也不通过移除产品 inert 或固定 sleep 绕过加载生命周期。

- Unit test feature view models/composables; component test critical editing and confirmation behavior.
- E2E covers project import, autosave/restart, planning, AI draft apply/cancel, backup and offline mode.
- Do not preserve browser/server mode; the product is Electron-only.
- Do not expose login, cloud sync, publishing, Langfuse or Python runtime status in UI.
- No operation may imply success before main confirms persistence.
- IPC type declarations are not runtime validation. Preload must validate the `{ ok, value | error }` envelope before unwrapping it, and high-value project/chapter/save/restore results must pass a business DTO decoder before renderer use. Malformed-response errors may identify the fixed channel but must never echo returned content, keys or paths; add channels to the decoder registry incrementally without pretending unregistered results are already covered.
- Multi-document continuation responses must keep the preview/adoption area bound to the invoked channel. Adoption receipts require their source and target fingerprints plus `adoptedAt`; affected-count objects require every area-specific gate field rather than accepting an empty object of superficially valid values.
- Automatic-planning responses must validate the complete proposal tree before renderer use. Preview channels require their current/candidate fingerprints and every layer-specific affected or preserved field; adoption metadata requires its formal timestamp and upstream/target fingerprints. Job status, stage and progress must agree, and completed progress may never exceed total progress.
- Research results must preserve traceable HTTP(S) sources and never expose credential values. Source-card results require a fixed source kind and content fingerprint; event results require time, characters, location, event and evidence. Bind candidate creation and formal approval states to their invoked channels while keeping legacy list reads compatible with older optional timestamps.
- Candidate adoption click tests must assert the persisted result, refreshed navigation and an actually visible success notice. Text merely present off-screen is insufficient; inline preview removal can leave the scroll position below the notice. Cancel must leave formal data unchanged.
- Test keyboard navigation, focus restoration, empty/error states and unsaved-change recovery.
- Task-center filters use native buttons with exactly one `aria-pressed=true`. Test Tab/Space/Enter against actual empty/full history, not only CSS classes, and verify hit targets at compact desktop size and 125% zoom. Electron native Enter tests must send the character event as well as keyDown/keyUp; measure focus outlines in device pixels because fractional Windows scaling rounds CSS border widths.
- 搜索测试必须断言输入查找词后焦点仍在搜索框、Enter/Escape 前后编辑正文逐字不变；只看匹配计数元素非空会把“没有匹配”误算成功。共享编辑器的可选 Boolean 开关若默认启用，必须使用显式默认值，不能依赖 undefined 绕过 Vue Boolean 自动转换。
- CodeMirror 搜索 Escape 必须优先于默认简化选区命令；测试须覆盖替换后焦点在正文的关闭路径，不只测搜索输入框。原生字段通过 change/keyup 提交，Electron insertText 不会生成真实 IME keyup，驱动应明确使用真实失焦提交再选择匹配。替换必须核对逐字结果、单步撤销/重做、恢复后保存与跨文档重载，不能只看高亮。
- Selection/AI rewrite smoke must assert a nonempty persisted fixture and exact rendered text before selecting, then a nonempty native selection. Equality of two empty strings proves nothing. Independent smoke entry points must seed their own prerequisites rather than rely on earlier full-suite steps. Inspect the failure screenshot and fixture source before diagnosing editor internals; never add editor state backdoors to make a driver pass.
- After replacing a textarea with a contenteditable editor, search every smoke path for textarea-only APIs such as `.value`, `readOnly` and `setSelectionRange`; migrating the primary scenario is insufficient. An asynchronously mounted control that is still missing means “not ready”, never “ready because `undefined` is not disabled”.
- Exercise large paste performance through a real paste event or native input path. `document.execCommand('insertText')` makes CodeMirror recover a large DOM mutation and measures the test driver more than the author workflow. Keep the persistence and render-time assertions, and verify the pre-backup draft actually reached authoritative storage before continuing.
- Visually inspect the final screenshots even when the smoke exits successfully. In particular, wrapper shortcuts must not leave both the product UI and an editor library's fallback panel open; add a DOM assertion for any duplicate control found by screenshot review.
- Writing workspace responsive smoke must assert at least 420 CSS px workbench width at the supported compact window, actual hits for all assistant header buttons, and resize-handle centers aligned with pane edges. Perform a wide/compact/wide roundtrip and compare both rendered pane widths and saved preferences. After resize/zoom, await two animation frames with a finite timeout before screenshots; layout metrics alone can precede compositor paint. Do not claim screenshot fidelity from a stale scaled frame.
- Mixed-diff/rebase smoke uses `.activitybar [data-activity="desk"]` rather than the retired “书稿” label. Before capturing the comparison, await two animation frames with a 2-second timeout (`rebase-preview-not-painted`), and assert dialog opacity/visibility plus the confirmation button's viewport bounds and `elementFromPoint`. A DOM-success result can accompany an old captured surface; inspect the image itself. Editing after candidate completion proves completed-candidate merging, not editing during active streaming. Preserve initial failures and chapter/focus diagnostics instead of treating a green retry as a root-cause fix.
- Model picker smoke must include all nine families, duplicate unknown-model names across APIs, a manual ID absent from `/models`, and an actual request asserting endpoint/model/credential with unchanged saved routing and prose. Geometry alone misses clipping by a parent: assert `elementFromPoint` for visible controls and inspect captures. The shared picker uses a root-level teleported panel identified by `data-picker`, not a descendant of its trigger; retain real focus restoration and outside-click behavior. Returning from settings must check the assistant's `aria-expanded`, not toggle it again merely because its input has not mounted yet.
- Outline CodeMirror rules have one paint owner: `.outline-writing-paper .cm-content`, with a 20px origin matching its text padding and a period equal to computed line-height. The wrapper and `.cm-scroller` must have no background image; repeating rules on all three layers causes doubled lines and scroll-phase drift. Verify wrapped text, blank paragraphs, deep scrolling, 100%/125% zoom and `editor-guides-hidden` in the isolated editor-parity smoke with `LANJIAN_SMOKE_OUTLINE_GUIDES=1`, then inspect captures. Do not infer alignment from matching CSS variables alone.
- The outline-guides fixture explicitly enables `lanjian-editor-guide-lines` before reload, independent of product defaults. After zoom, CodeMirror may remeasure virtual wrapped lines and correct the scroll anchor; settle at the target with a bounded retry before asserting the exact offset and phase. Do not relax alignment assertions or change the author's appearance preferences to make a smoke pass.
- Streaming smoke waits must wait for the required text, not merely the container mount. Keep a finite deadline and assert both the streamed fragment and its frozen context before exercising cancellation or retry.
- A crash-safety snapshot that exactly matches the chapter, title and body still held by the active editor must remain persisted but must not be surfaced as an interruption modal during checkpoint finalization. Once the editor no longer owns that exact text (reload, work-item switch or a genuinely divergent draft), the normal explicit recovery flow must remain available.
- The active-manuscript recovery smoke explicitly enables guides in its isolated preferences before reload. Before restoring, wait for the dialog animation and assert visible opacity, viewport bounds and `elementFromPoint` on the action; programmatic `.click()` alone can pass behind an invisible overlay. Compact layout checks distinguish workbench width from inset paper width: preserve the 420px workbench minimum and bound its combined paper gutters to 32px, alongside assistant separation. Never shrink product padding or change author settings merely to satisfy obsolete fixture assumptions.
- Long-form manuscript editing must reserve a dynamic bottom scroll margin for the active caret (bounded for both small and large windows), not merely add visual padding after the document. A real Enter-key smoke at the end of an overflowing document must prove the new indented paragraph is visible with upstream context. Keep font size in the single “版式” surface; do not duplicate small/large controls in the toolbar.
- Packaging/EXE is not a development gate until the user explicitly requests it; `electron-vite build` remains required.

> **Warning**: a click smoke must assert the post-success notice or resulting error state, not only the persisted file. A handler can finish its main write and then throw from a misspelled refresh function; storage assertions alone will pass while the user sees an English runtime error.

> **Warning**: replacing adoption metadata returned by main is not an author edit. Suppress exactly that next deep-watch autosave; otherwise a successful transaction briefly shows “候选有改动” and performs a redundant save. Candidate field edits must still clear their own adoption record and enter the normal autosave path.

> **Warning**: detailed-outline adoption must be exercised with real Electron clicks through preview and confirmation. Assert that one selected formal outline changes, other chapter outlines and the manuscript collection do not, and the UI still says `待复核`; DOM rendering alone cannot catch preload structured-clone failures or accidental gate bypass.

> **Warning**: TXT import click coverage must use a deliberately messy file, not only two clean headings. Assert the three ownership choices, visible duplicate/jump/reverse diagnostics, conservative checked count, and a post-persistence Chinese success notice. Modal close alone is not success because renderer refresh may still fail after main writes.
