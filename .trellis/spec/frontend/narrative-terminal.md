# 叙事档案终端与写作伙伴

本轮直接在 Vue/Electron 应用中实现；不以离线原型或设计平台画布代替真实组件。

## 视觉与布局边界

- `narrative-tokens.css` 定义语义色、8px间距、2px面板圆角、短过渡；`narrative-terminal.css` 将既有组件变量接到同一套令牌。浅色和墨夜都必须使用成对前景/背景，禁止在主题文字后硬编码浅底。
- 写作维持导航、章节树、正文、助笔四区；最新要求为能拖出主窗口的独立桌面宠物，顶栏保留恢复入口。使用无 parent 的透明 Electron BrowserWindow，不再挂载页面 CompanionPet，不增加第五列或缩短目录。窗口、IPC 与穿透契约见 [桌面伙伴](desktop-pet.md)。
- 正文保持 CodeMirror、阅读衬线字体与既有排版/行线设置。角色不管理文本、撤销、保存、任务采用或模型路由。
- 书架预览走只读目录服务，不通过激活作品来取得目录。未知每日字数/关联数据不能以总字数或假数据补齐。

## 角色控制与持久化

- `CompanionController` 是纯展示状态机；精细/Q版共用。任务反馈只在同一作品章节、同一任务从活动进入终态时短暂出现，恢复历史任务不播放完成反馈。
- `CompanionHost` 管理眨眼、阻尼视线和轻呼吸。隐藏/后台停止帧调度，中文组合及连续输入保持静止；减少动态效果优先于动作偏好。
- 作品库使用基于参考图整理的本地立绘，轻呼吸/鼠标视差服从减少动画。`DesktopPetWindow` 复用 `CompanionHost`，普通版使用立绘插槽，Q版暂用原创 SVG 占位，等待作者提供正式图片。普通立绘没有面部绑定，不能宣称 Live2D 或真实眨眼；两版共用展示状态机与本机偏好。
- `placeCompanion()` 仅是旧页面定位实现，不得用于替代真实桌宠。窗口位置在 main 使用屏幕 DIP 坐标恢复；主界面向独立窗口发送专注/安静状态，不授予桌宠编辑正文或绕过确认的能力。
- `lanjian-companion-v1` 仅保存本机外观偏好，全局默认与按作品覆盖分离。坏记录锁住正常写入；用户明确恢复时先备份原记录，写入失败不假报成功。

## 加载与键盘

- 冷启动阶段由初始化过程驱动；作品载入超过300ms才显示大页，不强制动画最短时长。
- 载入期间背景 inert，关闭/取消始终可见；首次聚焦关闭按钮，Escape 可退出，父层恢复有效入口焦点。
- 预览必须标识“非真实载入”，不能依赖超时自动关闭来测试实际可达性。

## 验证

- 角色纯状态与偏好：`companion-controller.test.ts`、`companion-preferences.test.ts`。
- 加载组件：`loading-terminal.test.ts` 和 `scripts/loading-terminal-smoke.mjs`。后者只是实际组件浏览器验证，不等同完整应用启动测试。
- 集成：`LANJIAN_SMOKE_STORAGE_ONLY=1`、`LANJIAN_SMOKE_NARRATIVE_ONLY=1` 运行 `scripts/electron-smoke.mjs`；只允许隔离烟测书，原生点击、非空输入、保存、刷新、专注、设置与窗口布局均需实际断言。
- 必须查看最终截图，不能仅以构建或选择器存在判断视觉合格。不得向真实作者作品写入测试内容。

### 桌面绘制时钟

- Electron 的后台节流可能暂停隐藏窗口的 RAF。双 RAF 是绘制检查，不是业务加载完成的证据；超时必须由主进程计时，不能与被节流的 renderer 共用时钟。
- 仅已验证临时用户目录和烟测书的测试窗口可关闭后台节流，并在 finally 恢复。截图仍须独立验证窗口非最小化、页面可见、业务就绪与真实像素变化；后台 RAF 通过不能冒充可见验收。
- 原先缺少现场诊断的随机超时不能据此被认定为确定根因。保留原失败，并记录窗口可见性、焦点、inert/对话框以及主进程截图截止信息。

## 问题修复记录

- 现有核对案卷内使用默认折叠的 `FindingHistoryPanel`，不另建页面或正文覆盖层。首批20条，按需展开更多；来源版本和曾确认修复的版本必须区分显示。
- 普通保存不等于修复。确认分为预览和显式提交，固定预览时的目标版本及决定 token；未保存、旧预览或并发修改时禁止提交并保留恢复提示。
- 壳层提交前先 flush 编辑器并复核 saved/dirty 状态，异步结果绑定作品会话及当前章。UI不得自行拼出已修复记录，只接受 main 刷新后的正式投影。
- “没有新的提示”不得暗示旧问题已解决；精确修复记录也不能作为本章所有检查通过的结论。

## 任务暂停与按钮可见性

- `paused` 与 `resuming` 是正式任务状态。写作轮询、任务提示点、恢复卡片和看板娘必须一致识别；继续任务期间仍可停止，暂停不播放完成反馈。已有子任务的暂停父记录只在历史中保留，不再提供重复继续。
- 任务中心刷新按钮使用组件自有的成对前景/背景、明确边框、键盘焦点和加载状态；不可继承 `.assistant-panel header button:hover` 对嵌套标题栏的白字透明底规则。
- 测试按钮存在或可点击不等于可见。对真正打开的任务页进行原生鼠标悬停，读取实际合成颜色并验证至少4.5文字对比度及中心点命中，紧接截图检查同态。`v-show` 隐藏页里的同名按钮不能作为可见状态验收目标。
- 原生状态的瞬时 `resuming` 用隔离数据库审计证明，不人为延迟产品以获得截图；服务重建/界面重开和真正进程重启必须在报告中区分。
