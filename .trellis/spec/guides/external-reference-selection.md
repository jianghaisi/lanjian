# External Reference Selection Guide

在参考外部项目开发 V3 功能前检查：

- [ ] 当前 V3 Trellis 任务写明要解决的具体用户结果，不使用“照搬整套项目”作为需求。
- [ ] 记录原始仓库、固定 commit/tag、访问日期、许可证与将复制或改写的精确路径。
- [ ] 用 Adopt / Adjust / Reject 记录每项能力，并解释不需要的权限、依赖和数据流。
- [ ] 保持 Electron/TypeScript、本地优先、每书隔离、无产品登录和候选确认原则。
- [ ] 不引入摄像头、录屏、云账号、远程记忆、另一套模型入口或泛化高权限 IPC，除非 V3 基线先明确改变。
- [ ] 为岚笺定义自己的 DTO、数据权威、错误、隐私、迁移和卸载边界。
- [ ] 根据风险添加单元/集成/真实 Electron/作者验收，而不是复用外部项目截图或测试结论。
- [ ] 将最终选择、精确接纳路径和验证记录在当前 V3 任务；旧 `REF-*` 清单没有当前权威。
