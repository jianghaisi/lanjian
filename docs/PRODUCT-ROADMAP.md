## 2. V3 状态词

| 状态 | 含义 |
| --- | --- |
| `v3-accepted` | 已由 V3 Trellis 任务明确接纳，满足 V3 PRD、测试和必要的作者验收，可以作为当前能力事实 |
| `candidate-for-v3` | 当前代码、设计或证据可能复用，但尚未完成 V3 准入 |
| `v3-rework` | 方向符合 V3，但实现或契约需要修改后重新验收 |
| `legacy/superseded` | V1/V2 内容，仅保留历史追溯，不驱动 V3 |
| `unrecognized` | 来源或意图尚不能确认，不得删除、提交或晋升 |

路线表中的 `in_progress` 只表示至少一个相关 Trellis 工作包正在执行，不代表该工作流已经 `v3-accepted`；`completed` 必须满足该行全部退出条件。

## 4. V3 准入规则

旧内容只有同时满足以下条件才能从候选晋升：

1. 符合 V3 产品基线与不可破坏约束。
2. 能证明仍被 V3 正式入口使用，而不是孤立文件、演示或废弃路径。
3. 在当前 V3 Trellis PRD 中列出复用路径、理由和验收方式。
4. 通过与风险相称的 V3 测试；涉及视觉、桌面操作或作者体验时完成相应人工验收。
5. 只把该任务认领的文件纳入提交，不吸收来源不明的工作树变化。

不满足上述条件的旧任务勾选、测试报告、截图、设计稿和代码均不能显示为 V3 完成度。

## 6. 变更规则
