# 后续更新计划

岚笺 0.1 是开发预览版。下面是后续持续完善的方向，既包含已有功能的改进，也包含尚未完成的工作；不代表这些能力已全部验收，也不承诺尚未确定的发布日期。

| 方向 | 后续重点 | 希望达到的体验 |
| --- | --- | --- |
| **UI 完善** | 统一视觉层级、主题与组件；完善窄窗口、不同缩放、中文输入、键盘操作和可访问性 | 书库、编辑器、设置和辅助面板更一致、更易用 |
| **书籍封面** | 完善封面选择与展示、标题排版、不同书名长度适配和书库卡片表现 | 每部作品有清晰、稳定、有辨识度的封面 |
| **插件系统** | 完善安装、更新、版本兼容、授权说明、组合配置和示例文档 | 作者能理解插件用途、控制权限并安全组合写作方法 |
| **写作流程优化** | 打磨资料 → 总纲 → 卷纲 → 章纲 → 正文的衔接、版本确认、候选审阅与中断恢复 | 上游依据清楚，作者始终决定何时生成、采用和定稿 |
| **开机动画** | 优化启动速度、加载反馈、动画与声音设置、低性能设备表现 | 启动过程美观且可控，动效不妨碍进入作品 |
| **桌宠互动完善** | 完善动作反馈、拖动、养成与专注互动；继续打磨可选语音和静音体验 | 桌宠响应自然，陪伴创作且不打扰输入 |
| **地图系统** | 完善地图创作、地点与事件关联、作者调整、保存恢复及可视化交互 | 地图成为理解世界和故事行程的实用工具 |
| **数据与发布质量** | 持续改进保存、备份、历史恢复、导入导出、安装升级与自动化验证 | 更新过程中优先保护作品、设置与历史 |

## 如何查看进展

- [GitHub Issues](https://github.com/jianghaisi/lanjian/issues)：反馈问题与讨论具体需求。
- [Releases](https://github.com/jianghaisi/lanjian/releases)：查看每个已发布版本真正交付的内容和已知限制。
- [产品基线](PRODUCT-BASELINE.md)：了解当前产品边界；路线条目只有在实现和验证后才会写入发布说明。

优先修复影响数据安全、基础写作和稳定性的缺陷，再逐步完善上面的体验。欢迎在反馈中说明使用场景、期望行为与可复现的问题。

0.1 首先提供 Windows x64 安装包、中文说明和现有在线体验。macOS/Linux 安装包、签名与自动更新不在本次已验证交付中。真实模型的长篇文学质量由作者持续审阅，不以单元测试数量代替。
