# 岚笺 0.1.0 · 开发预览

首个 Windows x64 安装版本，面向长篇小说创作的本地工作台。0.1 是持续迭代的起点，不代表 V3 所有方向已经完成。

## 下载与安装

- 下载本 Release 的 **Lanjian-0.1.0-Setup-x64.exe**。
- 对照 **SHA256SUMS.txt** 检查文件摘要，再运行安装器。
- 安装包**未签名**，Windows 可能提示未知发布者；校验摘要只验证下载字节，不代表代码签名。
- 无需先安装 Node.js、Python 或模型权重，即可建立作品并手工编辑。AI 接口与可选本地语音、模型需另行配置。

本次保留既有应用 ID、协议和数据身份，卸载配置不删除应用数据。请继续自行备份重要作品，不要手工清空旧配置或作品目录。

## 本版内容

- 本地作品管理、章节编辑、保存、历史、导入与导出。
- 资料、人物、世界设定、分层大纲、事件纪事，以及模型与写作候选的配置和审阅入口。
- Windows NSIS 安装包、岚笺应用与快捷方式图标、中文图文 README、贡献和部署指南。
- 按包依赖顺序执行的 CI，以及手动触发的 Windows Release 草稿工作流。
- [现有在线试用](https://lanjian.jiangai.space/)：游客可浏览公开参考书；登录和模型能力以站点实际配置为准。在线部署独立于本次桌面版本。

## 验证范围

发布检查覆盖共享包、桌面类型与架构、桌面合成数据测试、网页、托管服务和插件分发服务。安装检查使用全新配置与合成书库，验证真实安装、无密钥手工保存、原生窗口正常关闭、新进程重启、覆盖安装和卸载后的数据保留。源码与公开 Git 历史执行秘密扫描。

本轮桌面测试：**3708 通过 / 0 失败 / 6 跳过**。跳过项为 3 项需显式开启的长书/性能检查、2 项不随公开源码分发的私有作者工具检查，以及 1 项当前 Windows 拒绝创建文件符号链接的检查。共享契约 22 项、网页 3 项、托管服务 69 项、插件分发服务 8 项均通过。

运行资源检查包括 main、preload、renderer、插件 worker 与 WASM；安装包不包含作者私有书库、模型凭据、开发场景驱动或模型权重。

## 已知限制

`v0.1.0` 标签保留首版源码历史。首次 CI 暴露的插件市场预构建顺序已在 `main` 修正，安装包运行代码未改变。从该标签源码验证时，先运行以下命令（不要直接跳过中间的服务构建）：

```powershell
node scripts/ci.mjs install
npm --prefix services/plugin-marketplace run build
node scripts/ci.mjs check
```

- 仅验证 Windows x64；尚未提供 macOS / Linux 安装包、代码签名和自动更新服务。
- 部分插件、地图、桌宠和可选语音体验仍在持续完善，见 [后续更新计划](https://github.com/jianghaisi/lanjian/blob/main/docs/PRODUCT-ROADMAP.md)。
- 真实付费模型的文学质量、真实账号 OAuth 登录与每种硬件组合不属于本次自动验证。
- 网页生产构建存在大分块体积提示；首屏和下载体积仍有优化空间。
- 正文生成仍需作者确认当前总纲及对应卷纲、章纲；保存与采用候选不等同于确认。

反馈问题请提供版本、系统和最小复现；勿附 API Key、Cookie、私人书稿或未脱敏日志。
