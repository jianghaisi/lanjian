# 0.1.1 更新说明

- 作品库顶栏移除书名/类型搜索框和静态保存状态，保存功能保持不变。
- 模型设置移入作品库设置的第 04 项，写作插件顺延为第 05 项。保留未保存修改保护与返回设置操作。
- 修复兼容中转接口被参考型号规则误判为不支持工具调用的问题；官方接口的已知限制仍生效。
- 模型流式回复中断时提供更明确的提示，不执行未完整返回的工具调用。

这是 Windows x64 开发预览更新，不代表 V3 全部功能已验收。保留现有应用身份、配置和作品目录；安装包未进行代码签名。

本次源码验证包括类型检查、架构检查、75 项模型与导航测试、生产构建以及隔离 Electron 交互检查。安装包需按 [发布流程](../RELEASE.md) 完成实际安装和正常重启验证后使用。
