# 0.1.2 更新说明

本次更新修复模型工具续接，并让报错后的处理方法更清楚。

- 修复 Gemini 工具结果回传时空片段可能导致接口拒绝请求的问题，保留工具标识、思考签名与会话记录。
- 区分网络中断、服务繁忙、输出预算不足、内容拒绝、权限和额度问题，提示何时重试、何时检查设置或联系服务商。
- 模型测试成功明确显示“文字测试通过”，提醒尚未验证工具调用。
- 助笔失败后可“取回原要求”，保留已输入的草稿，确认发送后才发起新请求；提示先核对已完成的操作。
- 同步集成测试中的旧错误文案断言，保留错误隐私检查。

## 验证与限制

发布前须完成完整 CI、Windows 安装/保存/正常重启与下载摘要验证，实际结果记录在 GitHub Release 中。模型回归已覆盖四种远端协议的错误恢复、取消、超时、无额外重试及隐私保护。

真实接口诊断中，GPT 6.1 Sol 的 Chat / Responses 工具往返通过；多个 Gemini 型号与 Claude 也有通过证据。部分上游型号仍可能超时、返回 503 或无效回复，不能据此保证所有型号和思考模式可用。文字测试通过也不代表工具能力已验证。

此版本仍是 **Windows x64 开发预览**，不代表 V3 全部功能验收。安装包未进行代码签名，Windows 可能显示未知发布者；请从本仓库 Release 下载并核对 SHA-256。
