# 0.1.3 更新说明

修复缺少“正式父级大纲”时不知道去哪生成、生成后不知道如何采用的问题。

- 缺失提示明确是全书总纲、具体卷纲还是阶段纲，并给出准备路径，避免盲目重试。
- “谋篇 → 全书总纲”补充起步说明；“AI 生成总纲”打开创作筹备，显示生成进度与候选。已有候选只打开查看，不重复生成。
- 将候选采用的“下一步”移到长内容之前，显示人物、世界、力量体系、特殊优势四项前置进度；核对完成后可预览采用总纲。
- 导航保留未保存草稿保护；保存后继续能正常启动生成，切换作品不会误发请求。
- 保存、候选采用和作者确认仍然分开，不自动确认大纲或生成正文。
