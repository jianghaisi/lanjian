# 0.1.6 更新说明

改进自动谋篇创作蓝图的格式错误提示，并让新卷纲直接拆解为章纲。

- 创作蓝图返回空内容、数组、未闭合对象或 JSON 语法错误时，提示对应类别和检查方向。首次与最后一次模型返回仍保存在失败记录中；一次格式修复仍失败时不会改写正式大纲。
- 新发起的逐层谋篇按“总纲→卷纲→章纲”展开。一个卷可以分批续拆；下一批会参考已有章名、顺序和最后一章内容，采用前核对父稿与同卷目录版本。
- 新书界面不再引导建立阶段纲。旧阶段纲仍可读取和编辑；旧版候选按其冻结的生成方法预览与采用，不迁移或删除现有作品内容。
- 候选采用不等于作者确认。生成正文前，作者仍需明确确认当前总纲、对应卷纲和章纲。

## 下载与升级

## 验证与限制

本版通过定向回归、类型检查和构建后制作安装包。完整 CI、实际安装与覆盖升级、附件摘要核对的最终结果以本 Release 页面附列的验证记录为准。用户反馈的原始模型返回未能取得，因此不能确定那次失败究竟是哪一种 JSON 格式错误；提示改进不会保证模型每次都返回有效 JSON。

Windows x64 安装包仍是未签名开发预览。没有修改真实作者作品，也没有代作者确认大纲或生成正文。
