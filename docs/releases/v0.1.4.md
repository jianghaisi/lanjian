# 0.1.4 更新说明

新增 FastAIToken 赞助展示，使用官方 Logo 和岚笺专属邀请链接。

- GitHub 中英文介绍、官网页脚、网页与桌面作品库设置均可查看赞助商。
- 作品内“设置 → 高级 → 关于岚笺”和桌面模型接口页增加赞助卡片。
- 所有赞助入口保留邀请参数；仅在点击时打开外部网站，不改变模型配置或岚笺积分。
- 支持键盘关闭和焦点返回，并检查手机窄屏、三套主题及 Windows 125% 缩放。

## 下载与升级

- [Windows x64 安装包](https://github.com/jianghaisi/lanjian/releases/download/v0.1.4/Lanjian-0.1.4-Setup-x64.exe)
- [SHA256SUMS.txt](https://github.com/jianghaisi/lanjian/releases/download/v0.1.4/SHA256SUMS.txt)

退出岚笺后运行安装包，沿用原设置和作品目录。当前没有自动更新检测或新版本提醒，需要手动下载升级。

## 验证与限制

赞助入口已通过双端类型检查、构建、桌面隔离交互和浏览器测试。发布前还须完成完整 CI、实际安装/覆盖安装/卸载数据保留与附件摘要核对，结果在 Release 中记录。

此版本仍是 Windows x64 开发预览，安装包未进行代码签名，不代表 V3 全部功能验收。未修改真实作者作品，也未替作者确认大纲。其他操作系统未在本次验收范围内。
