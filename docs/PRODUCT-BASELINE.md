# 岚笺产品基线

当前产品研发代际为 V3；0.1.0 是首次公开开发预览发布号。公开发布不表示全部 V3 能力已经完成。

## 产品目标
为长篇小说提供一个本地桌面创作工作台，把定义、参考、设定、分层大纲、事件与正文放在同一部作品中；线上体验作为独立托管模式保留账号隔离与费用边界。

## 必须保持的约束
- 全局总纲 → 卷纲 → 章纲 → 正文逐层展开，事件记录时间、人物、地点与事件。
- 正式内容由作者决定；AI 输出、外部导入和讨论先作为候选。
- 作者明确确认当前总纲、对应卷纲和章纲后，才允许发起对应正文生成；上游修改导致相关确认失效。
- 动态境界与固定系统界面模板属于配置，生成按当前作品配置使用。
- 保存、候选采用和正式确认是不同动作。
- 本地文件/SQLite 的实际权威与历史版本必须一致，失败可见、冲突不静默覆盖。
- 模型凭据与用户书稿不进入源码、日志、截图或公开发布包。
- 多书任务始终绑定其发起作品；切换标签不改变任务所属。
- 创作方法可作为插件替换；保存、权限、费用、版本恢复及确认留在核心。

详细能力和限制以当前 README、测试证据与 Release 说明为准。私人作品、作者反馈及内部任务日志不随本公开工程分发。
